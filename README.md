# ASOG 고객 전용 질문지

진행 중인 고객만 쓰는 비공개 페이지입니다.
공식 사이트(askillofgod/asog)와 저장소·배포가 완전히 분리되어 있습니다.

## 파일
- `index.html`   고객이 보는 질문지
- `admin.html`   대표가 보는 관리자 화면
- `questions.js` 질문 내용 — 고칠 일이 있으면 여기만 보시면 됩니다
- `supabase.js`  저장·조회용 라이브러리 (직접 고치지 마세요)

## 접속 방법
로그인이 없습니다. 주소 뒤의 코드가 곧 열쇠입니다.

- 고객   `.../?k=<고객코드>`
- 관리자 `/admin.html?a=<관리자코드>`

관리자 주소는 모든 고객의 답변이 보이는 곳이니 절대 공유하지 마세요.

## 고객 추가
관리자 화면에서 `+ 고객 추가` → 회사명과 묶음 선택 → 링크가 만들어집니다.
파일을 고치거나 다시 배포할 필요가 없습니다.

## 질문 수정
`questions.js` 의 `MODULES` 만 고치고 push 하면 반영됩니다.
묶음(module)은 고객마다 켜고 끌 수 있습니다.

- `common`     공통 — 모든 고객
- `migrate`    기존 데이터 이전 — 기존 사이트가 있을 때
- `visionfilm` 비전필름 전용
- `closing`    마무리 — 항상 맨 뒤에 붙습니다

새 업종 묶음이 필요하면 `MODULES` 에 `{ id:"...", name:"...", steps:[...] }` 를 추가하시면
관리자 화면의 묶음 선택지에 자동으로 나타납니다.
